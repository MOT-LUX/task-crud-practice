# task-crud-practice

## 概要

COACHTECH 教材 Tutorial 11-2「タスク管理APIのCRUD実装」で作成した成果物です。
タスクの登録・取得・更新・削除ができる、タスク管理APIを作りました

## 使用技術

- PHP 8.x
- Laravel 10.x
- REST API（CRUD）
- API Resources、FormRequest（バリデーション）

## 学んだこと

- POSTMANを使った、動作確認を学びました
- GET：取得　POST：作成　PUT：タスクを更新　DELETE: 削除　それぞれの役割を学びました
-

## 動作確認

POSTmanでAPIにリクエストを送り、HTTPステータスコードとレスポンスの内容を確認しました。
